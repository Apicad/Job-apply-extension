# Job Apply Assistant 0.6.6 — use saved experience for partial answers

The 0.6.5 live Smartcuts test recovered from the reply-format error but left all four writing questions blank because completeness checks required every requested detail. Autofill now uses supported technology and project details while keeping missing durations, pride and ownership confirmations visible in the sidebar. It does not assert those missing personal facts. A work-style preference still requires an explicit saved preference; an unrelated experience list is not substituted for a direct choice.

The helper now drafts a motivation from the applicant's saved experience and job opportunity rather than requiring a prewritten excitement statement. Job descriptions are read from bounded public page metadata or description sections, excluding forms and editable controls. On Lever's separate apply page, the extension may read the exact same-origin public job URL without query tokens, credentials, redirects, navigation or submission. The read has a three-second deadline and a 250 KB response limit. Job text remains untrusted context, never applicant evidence. Existing answers and source/context write guards remain in place.

Local regressions cover supported partial project/technology answers, withheld unsupported assertions, retained review notes on a repeated run, job context in the AI request, and bounded public context extraction. Tests remain owner-local at the owner's request. Independent 0.6.4 Grok results do not certify this release. Autosave/reset forms and delayed fields remain known gaps; no universal form support is claimed.
