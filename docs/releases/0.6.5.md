# Job Apply Assistant 0.6.5 — AI answer recovery

The live Smartcuts test of 0.6.4 filled saved details but left every AI answer blank on two runs with “Invalid sentence segments or missing-information notes.” A synthetic reproduction found that the native helper permits an empty segments list with missing-information notes, while the extension rejected that response. The live payload was not captured, so this reproduces a compatible failure path rather than proving the exact live payload.

Missing-information-only replies now become unresolved sidebar items with no text inserted. A question-specific generation or validation error is also retained as a warning, and processing continues to subsequent questions. Cancellation, navigation, and changes to saved facts still stop the run. Nothing is submitted automatically.

Owner-local regression checks cover empty replies, malformed replies, continued filling of a subsequent supported answer, and warning retention over two runs. The GitHub snapshot intentionally excludes test sources at the owner's request. Live acceptance must be recorded separately for the exact release; local mocked-AI tests do not certify live model output or universal employer-form compatibility.

PR #2 remains subject to owner review before merging. Independent Grok audits of 0.6.4 are separate evidence and do not certify this update.
