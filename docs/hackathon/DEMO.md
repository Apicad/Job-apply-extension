# Three-minute HackerSquad recording script

Use a synthetic Chrome profile, the production build, a local labeled sample and an available authorized free AI chat. Prepare the workspace and chat before recording. Record inside HackerSquad as required by the supplied submission plan. Do not hide the manual copy/paste step or show a historical replay as live AI. No recording or submission has been made by this build.

| Time | Show and say |
| --- | --- |
| 0:00–0:20 | “Application questions repeat, but applicants still need to check every claim. This is fictional Ada and a synthetic application. The assistant drafts from saved experience and leaves submission to me.” Load sample, scan, point at unchanged fields. |
| 0:20–0:45 | Select the project question and two facts. Show the full payload, distinguish job requirements from applicant facts. “Only these selected facts and this reviewed context go to my AI chat.” Copy the request. |
| 0:45–1:20 | Paste into the available AI chat, copy the real JSON response back and validate it. Open each sentence's source. “These are the original saved snippets and revisions. A valid citation is not proof; I compare the claims.” If provider latency exceeds the budget, stop/rehearse again; do not conceal a cut as live generation. |
| 1:20–1:55 | Edit one phrase conservatively; point out the removed mappings and retained original trace. Apply edits, confirm review, approve, then explicitly save. Close/reopen the workspace and inspect the saved answer. “Approval did not save automatically.” |
| 1:55–2:35 | Preview the approved textarea plus profile fields and fill. Show exact text and verified outcomes; point to preserved prefilled/unsupported/consent fields and “Not submitted.” Open a second sample job; demonstrate that a saved answer is only a review candidate (or current-application scope rejects it). |
| 2:35–3:00 | “We added source-visible answer drafting, exact approval and persistent reviewed reuse on top of an existing conservative fill foundation. Copy/paste is the AI connection; custom widgets, LinkedIn import and résumé tailoring are deferred. The README gives setup and the exact audited source snapshot. I still review and submit.” |

Target 170 seconds, leaving 10 seconds buffer. This is a timed storyboard; a complete human recording rehearsal has not yet been timed. AI latency is variable. Use the committed screenshots and response only as explicitly labeled historical backup, alongside the live route and actual smoke evidence.

Before submission: confirm team/individual rule acceptance, free judge access, project license/credits, public source availability at the exact candidate SHA, in-platform recording playback and submission receipt. Publication, visibility changes, push and event submission remain owner actions.
