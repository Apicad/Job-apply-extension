Your first application, without sending anything.

Local practice pages for the hackathon. These reproduce selected Greenhouse, Lever, and Ashby form patterns; they are not employer websites or a promise of universal compatibility.

1. Save a fictional profile

Open the extension’s Profile home. Download the sample résumé, upload it, review the extracted fields, and save. Confirm:

  • Ada Lovelace · ada@example.com · (415) 555-0100
  • San Francisco · California · United States
  • Example Community College · Computer Science coursework

Keep eligibility and demographic answers blank. Use a separate Chrome profile for this practice if you already have a personal profile saved.

2. Try three application formats

  1. Greenhouse-style application: contact fields, exact dropdown matches, education, upload and checkbox review.
  2. Lever-style application: full name, contact details, links and upload. Location and unsupported questions need review.
  3. Ashby-style application: form-less layout, contact fields and upload. Custom controls need review.

On each page, click the extension’s toolbar icon, then Autofill. Inspect the page and sidebar. Change one filled value yourself, run again, and confirm your edit stays. Do not click Submit. Reload a practice page to reset it.

The practice server blocks network connections and form submissions. Any mock Submit control only changes local test state; it cannot send an application.

3. Preview AI documents

Connect your own signed-in Codex CLI using the included START-HERE guide. In Profile home, review the saved fictional experience and project notes and enable the ones you want included. Use this target:

Example Tools seeks a junior developer to maintain Python CSV validation tools, build React interfaces, and document edge cases. This is a fictional demonstration job.

Career direction: Junior software development focused on practical tools and clear documentation.

Click Create résumé & cover letter. Preview both tabs. Edit wording, inspect sources and warnings, then mark both reviewed to enable Word/PDF export. AI account usage limits apply. If connection or generation fails, report the error; an old saved draft is not a successful new generation.

4. Let AI draft an application answer

With your fictional experience saved and AI enabled in the sidebar, open the AI-answer practice application and click the toolbar icon, then Autofill. The supported “Describe a relevant project” question gets a new draft from your saved facts. You do not prewrite the answer. Review its sources, edit if needed, then use Use answer to fill that exact text. Leave Submit untouched.

This demo supports two project-question wordings; other free-text questions remain manual. Up to 20 saved experience/project notes can supply evidence. A larger automatically ranked project database is a later feature.
